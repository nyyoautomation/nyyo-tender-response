# Public tender response pack — Nyyo Automation

Live demo: https://nyyoautomation.github.io/nyyo-tender-response/

Turn a **construction / public tender** package into a **review-ready** proposal pack (technical proposal by scoring criteria, compliance matrix, document checklist). Export DOCX / PDF in the browser.

**Sample data is 100% fictional.** Human review required before any real bid.

## What’s real vs pre-computed

| Step | Demo behaviour |
|---|---|
| Sample extraction (criteria, deadlines, requirements) | **Pre-analysed sample** (stored results, badge on page) |
| Knowledge-base search + citations | **Live** in-browser BM25 |
| Price / schedule / team / variant form | **Live** |
| Proposal assembly + matrix + checklist | **Live** assembly in browser |
| DOCX export (`docx.js`) | **Live** |
| PDF | Print / Save as PDF |
